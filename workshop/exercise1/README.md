# Northwind Energy – Workshop Application

A fictional residential energy self-service portal used in the
**AI-enabled Software Delivery – Session 1** workshop.

---

## Quick start

```bash
npm install   # once only
npm run dev   # start the dev server
```

Open **http://localhost:5173** in your browser.
