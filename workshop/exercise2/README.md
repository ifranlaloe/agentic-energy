# Northwind Energy – Workshop Application

A fictional residential energy self-service portal used in the
**AI-enabled Software Delivery – Session 1** workshop.

---

## Quick start

```bash
npm install   # once only
npm run dev   # start the dev server
```

Open **http://localhost:5173** in your browser.

---

| Page | Path |

## Exercise 1

> **Add an energy-offer comparison experience.**
>
> Customers should be able to compare three energy offers and choose one.
>
> Use Claude however you want.
>
> Watch what the agent does while it works.

Open Claude Code, describe what you want, and let the agent work.
The three energy plans (Flex, Zeker, Groen) are already in the application data.

---

## Exercise 2

> **Help customers choose an energy plan.**
>
> Customers can already compare our three energy plans, but some still
> struggle to decide which one fits their situation.
>
> Add a small experience that helps them make a choice.
>
> Before changing anything:
>
> **Research → Plan → Human judgment → Implement**
>
> Relevant product, UX, and engineering context is available in `/docs`.
>
> Do not implement until you are comfortable with the plan.
